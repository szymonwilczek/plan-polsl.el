Emacs package integrating the timetable system of the *Silesian University of Technology* ([[https://plan.polsl.pl/][plan.polsl.pl]]) for student groups, faculty teachers, and rooms with *Org-mode*, *Org-Agenda*, and a dedicated in-memory timetable buffer.

* What's inside:

- *Timetable Buffer* (~M-x plan-polsl~): Schedule viewer rendered in separate window.
- *Default Current Week View:* Adjusts to the current academic week with calendar dates on each day header.
- *Interactive Search* (~M-x plan-polsl-search~):
  - *Teachers:* Surname completion across all university faculty members.
  - *Groups & Rooms:* Tree navigation (Faculty -> Programme -> Semester -> Group).
- *Org-Agenda Integration:* Recurring timestamps anchored to the academic semester start date.

** How to Find Your Schedule ID

You can obtain your ~plan-polsl-id~ and ~plan-polsl-type~ using either of two methods:

*** Method 1: Directly inside Emacs (Recommended)
1. Run ~M-x plan-polsl-search~.
2. Choose your category.
3. Select your teacher name, student group, or room.
4. Schedule opens in the ~*Plan PolSL*~ buffer, displaying the ID in the header banner.
5. Copy the ID into your configuration.

*** Method 2: From the browser URL
Open the schedule on [[https://plan.polsl.pl/][plan.polsl.pl]] and check the browser address bar:
- *Student Group:* ~plan.php?type=0&id=343266256~ $\to$ ~plan-polsl-id "343266256"~, ~plan-polsl-type 0~
- *Teacher:* ~plan.php?type=10&id=600~ $\to$ ~plan-polsl-id "600"~, ~plan-polsl-type 10~
- *Room / Resource:* ~plan.php?type=20&id=51112~ $\to$ ~plan-polsl-id "51112"~, ~plan-polsl-type 20~

The address bar probably will be empty, to have this displayed, do the following:
#+BEGIN_QUOTE
I'm using Mozilla Firefox, so I'm going with their convention. Probably you should check that
out for yourself if you are using something different.
#+END_QUOTE

1. Right click near the plan table.
2. From the context menu choose: ~This frame (pl. Ta ramka)~ -> ~Show only this frame (pl. Pokaż tylko tę ramkę)~
3. Congratulations! You've got yourself fully armed address bar with desired parameters.

** Configuration Examples (use-package)

Configure the package parameters directly in your Emacs configuration:

*** 1. Student Group (~type=0~)
#+begin_src elisp
  (use-package plan-polsl
    :vc (:url "https://github.com/szymonwilczek/plan-polsl.el")
    :commands (plan-polsl plan-polsl-sync plan-polsl-open-plan plan-polsl-search plan-polsl-refresh-teachers)
    :custom
    (plan-polsl-id "343266256")                                    ;; Group ID from plan.polsl.pl
    (plan-polsl-type 0)                                            ;; 0 = student group
    (plan-polsl-target-file "~/Dokumenty/writings/plan-polsl.org") ;; Destination Org file
    (plan-polsl-auto-add-to-agenda t))                             ;; Add to Org-Agenda
#+end_src

*** 2. Academic Teacher (~type=10~)
#+begin_src elisp
  (use-package plan-polsl
    :vc (:url "https://github.com/szymonwilczek/plan-polsl.el")
    :commands (plan-polsl plan-polsl-sync plan-polsl-open-plan plan-polsl-search plan-polsl-refresh-teachers)
    :custom
    (plan-polsl-id "600")                                          ;; Teacher ID
    (plan-polsl-type 10)                                           ;; 10 = academic teacher
    (plan-polsl-target-file "~/Dokumenty/writings/plan-polsl.org")
    (plan-polsl-auto-add-to-agenda t))
#+end_src

*** 3. Classroom / Lab Room (~type=20~)
#+begin_src elisp
  (use-package plan-polsl
    :vc (:url "https://github.com/szymonwilczek/plan-polsl.el")

    :custom

#+end_src

** Interactive Commands

| Command                         | Description                                                            |
|---------------------------------+------------------------------------------------------------------------|
| ~M-x plan-polsl~                  | Open ~*Plan PolSL*~ buffer for your configured default schedule.         |
| ~M-x plan-polsl-search~           | Search for any teacher, group, or room timetable.                      |
| ~M-x plan-polsl-refresh-teachers~ | Force update the local cache of academic teachers from plan.polsl.pl.  |
| ~M-x plan-polsl-sync~             | Download and update your schedule in the Org-mode file for Org-Agenda. |
| ~M-x plan-polsl-open-plan~        | Open the generated ~plan-polsl.org~ file.                                |

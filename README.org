*plan-polsl.el* to pakiet dla GNU Emacsa integrujący oficjalny system planów zajęć *Politechniki Śląskiej* ([[https://plan.polsl.pl/][plan.polsl.pl]]) dla grup studenckich oraz nauczycieli akademickich z *Org-mode*, *Org-Agenda* oraz dedykowanym podglądem w buforze pamięci.

Pobiera plan bezpośrednio z serwerów uczelni, parsuje współrzędne siatki godzinowej, sal i grup/sekcji, wyświetla go w dedykowanym buforze ~*Plan PolSL*~ oraz synchronizuje z kalendarzem Org-Agenda.

* Możliwości

- *Integracja z plan.polsl.pl*
- *Filtrowanie sekcji laboratoryjnych*
- *Znaczniki powtarzalności*
- *Rejestracja w Org-Agenda*

* Konfiguracja (use-package)

Wszystkie parametry konfiguruje się bezpośrednio w definicji pakietu w Emacsie:

#+begin_src elisp
  (use-package plan-polsl
    :load-path "~/Dokumenty/GitHub/plan-polsl.el"
    :commands (plan-polsl plan-polsl-sync plan-polsl-open-plan)
    :custom
    (plan-polsl-id "343266256")                                    ;; ID grupy lub nauczyciela z plan.polsl.pl
    (plan-polsl-type 0)                                            ;; 0 = grupa studencka, 10 = nauczyciel, 20 = sala
    (plan-polsl-target-file "~/Dokumenty/writings/plan-polsl.org") ;; Ścieżka docelowa pliku Org
    (plan-polsl-auto-add-to-agenda t))                             ;; Dodaj do Org-Agenda
#+end_src

* Komendy interaktywne

| Komenda                  | Opis                                                                                    |
|--------------------------+-----------------------------------------------------------------------------------------|
| ~M-x plan-polsl~           | Otwiera dedykowany bufor ~*Plan PolSL*~ z czytelnym podglądem całego planu w pamięci RAM. |
| ~M-x plan-polsl-sync~      | Pobiera i aktualizuje Twój plan zajęć do pliku Org-mode dla Org-Agenda.                 |
| ~M-x plan-polsl-open-plan~ | Otwiera wygenerowany plik ~plan-polsl.org~.                                               |

Timetables of the *Silesian University of Technology* ([[https://plan.polsl.pl/][plan.polsl.pl]]) for groups, teachers and rooms in Emacs: a timetable buffer, *Org-mode* and *Org-Agenda*. Optionally, your personal timetable from *USOS* ([[https://usosapi.polsl.pl/][usosapi.polsl.pl]]).

* What's inside:

- *Timetable Buffer* (~M-x plan-polsl~): Asynchronous timetable viewer.
- *Current Week View:* Opens on the current academic week, with dates.
- *Course Inspector:* ~RET~ shows full class details in a side window.
- *Search* (~M-x plan-polsl-search~): Fuzzy search for teachers, rooms and groups.
- *Course Notes* (~n~): A note for the class at point, in a directory per course. See [[#course-notes][Course Notes]].
- *Events* (~c~ / ~e~ / ~D~): Dean's hours, days off, tests and exams in one synced Org file. See [[#events][Events]].
- *Org-Agenda* (~M-x plan-polsl-sync~): Exports the timetable to an Org file.
- *USOS* (~M-x plan-polsl-usos-login~): Your personal timetable, with exact dates. See [[#usos-integration][USOS Integration]].

** How to Find Your Schedule ID

Get ~plan-polsl-id~ and ~plan-polsl-type~ in one of two ways:

*** Method 1: Directly inside Emacs (Recommended)
1. Run ~M-x plan-polsl-search~.
2. Choose a category (group, teacher or room) and a timetable.
3. Copy the ID from the header into your configuration.

*** Method 2: From the browser URL
Open the timetable on [[https://plan.polsl.pl/][plan.polsl.pl]] and read the URL:
- *Student Group:* ~plan.php?type=0&id=343266256~ $\to$ ~plan-polsl-id "343266256"~, ~plan-polsl-type 0~
- *Teacher:* ~plan.php?type=10&id=600~ $\to$ ~plan-polsl-id "600"~, ~plan-polsl-type 10~
- *Room / Resource:* ~plan.php?type=20&id=51112~ $\to$ ~plan-polsl-id "51112"~, ~plan-polsl-type 20~

The timetable sits in a frame, so the address bar does not show it. In Firefox:

1. Right click near the timetable.
2. Choose ~This frame (Ta ramka)~ -> ~Show only this frame (Pokaż tylko tę ramkę)~.

** Configuration Examples (use-package)

*** 1. Student Group (~type=0~)
#+begin_src elisp
  (use-package plan-polsl
    :vc (:url "https://github.com/szymonwilczek/plan-polsl.el" :branch "main")
    :custom
    (plan-polsl-id "343266256")                                    ;; Group ID from plan.polsl.pl
    (plan-polsl-type 0)                                            ;; 0 = student group
    (plan-polsl-target-file "~/Dokumenty/writings/plan-polsl.org") ;; Destination Org file
    (plan-polsl-auto-add-to-agenda t))                             ;; Add to Org-Agenda
#+end_src

*** 2. Academic Teacher (~type=10~)
#+begin_src elisp
  (use-package plan-polsl
    :vc (:url "https://github.com/szymonwilczek/plan-polsl.el" :branch "main")
    :custom
    (plan-polsl-id "600")                                          ;; Teacher ID
    (plan-polsl-type 10)                                           ;; 10 = academic teacher
    (plan-polsl-target-file "~/Dokumenty/writings/plan-polsl.org")
    (plan-polsl-auto-add-to-agenda t))
#+end_src

*** 3. Classroom / Lab Room (~type=20~)
#+begin_src elisp
  (use-package plan-polsl
    :vc (:url "https://github.com/szymonwilczek/plan-polsl.el" :branch "main")
    :custom
    (plan-polsl-id "51112")                                        ;; Room ID (e.g. Aula A Alstom)

#+end_src

** Timetable Width

The timetable is at most 120 columns wide (less in a narrower window);
longer text wraps between words. Set ~plan-polsl-view-width~ to change
the limit, or to ~nil~ to use the whole window:

#+begin_src elisp
  (setq plan-polsl-view-width 100)
#+end_src

** Semester Start Date

Week numbers and odd/even weeks are counted from the semester start.
Enter the date announced by the dean once per semester:

#+begin_src
  M-x plan-polsl-set-semester-start RET 2026-10-01 RET
#+end_src

~2026-10-01~ and ~01.10.2026~ both work. Week 1 is the week containing
that day. The date is saved in ~~/.local/share/plan-polsl/semester.eld~.

Without it, ~plan-polsl-semester-start~ is used, or else October 1st
(winter) or early March (summer). A date older than 26 weeks is
ignored, so last semester's date never shifts the parity.

** Course Notes
:PROPERTIES:
:CUSTOM_ID: course-notes
:END:

Set the notes directory:

#+begin_src elisp
  (use-package plan-polsl
    :custom
    (plan-polsl-notes-directory "~/Dokumenty/studia/notatki"))
#+end_src

Press ~n~ on a class (or in its ~RET~ details):

1. The course directory is named after its initials:
   /Analiza danych i inteligencja obliczeniowa/ becomes ~ADIIO~. Accept
   the name with ~RET~ or edit it. Skipped when the directory exists.
2. Type the file name with its extension, e.g. ~wyklad-1.org~.
3. The file is created if needed and opened in another window.

A changed directory name is remembered per course in
~~/.local/share/plan-polsl/notes.eld~.

** Events
:PROPERTIES:
:CUSTOM_ID: events
:END:

Dean's hours, days off, tests and exams live in one Org file. Keep it
in a synced repository (e.g. your dotfiles) to share it across devices:

#+begin_src elisp
  (use-package plan-polsl
    :custom
    (plan-polsl-events-file (expand-file-name "polsl-wydarzenia.org" user-emacs-directory)))
#+end_src

*** Adding and editing
- ~c~ on a day creates an event. The minibuffer asks for the type,
  date, hours (blank = whole day), course, room and name. On a class,
  its hours, course and room are prefilled.
- ~e~ edits the event at point, with every step prefilled.
- ~D~ deletes it.

The file is plain Org, so you can also edit it by hand. Notes under an
event survive ~e~:

#+begin_src org
  ,* Godziny dziekańskie: inauguracja :dziekanskie:
  <2026-10-01 czw 12:00-18:00>

  ,* Kolokwium 1 :kolokwium:
  :PROPERTIES:
  :PRZEDMIOT: Analiza danych i inteligencja obliczeniowa
  :SALA:     416b
  :END:
  <2026-11-19 czw 14:00-16:15>
  Rozdziały 1-3, kalkulator.

  ,* Przerwa świąteczna :wolne:
  <2026-12-22 wto>--<2027-01-06 śro>
#+end_src

The tag is the type: ~dziekanskie~, ~wolne~, ~kolokwium~, ~egzamin~,
~projekt~, ~odrabianie~ or ~inne~. The file is reread when it changes.

*** How events are shown
- *Dean's hours and days off* appear next to the day heading; classes
  they overlap are struck through and marked /ODWOŁANE/.
- *Other events* appear among the day's classes; ~n~ on a test opens
  its course notes.
- *Upcoming events* (next ~plan-polsl-events-upcoming-days~ days, 14 by
  default) are listed in the header.
- *Org-Agenda:* the events file is added to ~org-agenda-files~, and
  ~plan-polsl-sync~ leaves cancelled classes out.

** USOS Integration
:PROPERTIES:
:CUSTOM_ID: usos-integration
:END:

Use your *personal* USOS timetable instead of a group one. Once you log in, ~M-x plan-polsl~ and ~M-x plan-polsl-sync~ use USOS.

No keys ship with the package: register your own free /consumer key/ and log in with your USOS account.

*** 1. Register a USOS API consumer key
1. Open [[https://usosapi.polsl.pl/developers/][usosapi.polsl.pl/developers]] and log in with your USOS account.
2. Register an application (any name).
3. Note the *Consumer Key* and *Consumer Secret*. Keep the secret private.

*** 2. Enter the key in Emacs
Run ~M-x plan-polsl-usos-setup~ (or just ~plan-polsl-usos-login~) and paste the key and secret.

They are saved to ~~/.local/share/plan-polsl/usos-consumer.eld~ (mode ~0600~), outside your Emacs configuration, so public dotfiles stay clean.

*** 3. Log in
1. Run ~M-x plan-polsl-usos-login~.
2. Allow access in the browser (the URL is also in the kill ring).
3. Paste the PIN from USOS into the minibuffer.

The token is saved in ~~/.local/share/plan-polsl/usos-token.eld~ (mode ~0600~; a ~.gpg~ suffix encrypts it). Requested scopes: ~studies~ and ~offline_access~.

~M-x plan-polsl-usos-logout~ revokes the token; with ~C-u~ it also forgets the key.

*** Alternative: key in configuration and auth-source
Or set ~plan-polsl-usos-consumer-key~ and put the secret in ~~/.authinfo.gpg~:

#+begin_example
machine usosapi.polsl.pl login YOUR_CONSUMER_KEY password YOUR_CONSUMER_SECRET
#+end_example

A key saved with ~plan-polsl-usos-setup~ wins.

*** How it behaves
- *Default timetable:* ~M-x plan-polsl~ opens USOS; ~C-u M-x plan-polsl~ opens plan.polsl.pl.
- *Week by week:* weeks are fetched on demand and cached; ~r~ refetches.
- *Exact dates:* holidays and cancelled classes are reflected; weekends show when they have classes.
- *Details:* ~RET~ shows lecturers, room, building and a USOSweb link.
- *Org-Agenda:* ~s~ exports ~plan-polsl-usos-sync-weeks~ weeks with dated timestamps.
- ~plan-polsl-usos-default~ set to ~nil~ keeps plan.polsl.pl as default (USOS via ~M-x plan-polsl-usos~).

*** USOS options

| Variable                        | Default                                     | Description                                                  |
|---------------------------------+---------------------------------------------+--------------------------------------------------------------|
| ~plan-polsl-usos-consumer-file~   | ~~/.local/share/plan-polsl/usos-consumer.eld~ | Where ~plan-polsl-usos-setup~ stores the key and secret.       |
| ~plan-polsl-usos-token-file~      | ~~/.local/share/plan-polsl/usos-token.eld~    | Where the access token is stored (use ~.gpg~ to encrypt).      |
| ~plan-polsl-usos-consumer-key~    | ~nil~                                         | Alternative: consumer key set in the configuration.          |
| ~plan-polsl-usos-consumer-secret~ | ~nil~                                         | Alternative: secret when auth-source has no entry.           |
| ~plan-polsl-usos-default~         | ~t~                                           | Prefer the USOS timetable in ~plan-polsl~ and ~plan-polsl-sync~. |
| ~plan-polsl-usos-sync-weeks~      | ~16~                                          | Weeks exported to Org by ~plan-polsl-sync~.                    |
| ~plan-polsl-usos-language~        | ~"pl"~                                        | Language of course names (~"pl"~ or ~"en"~).                     |
| ~plan-polsl-usos-timeout~         | ~15~                                          | Seconds before a USOS request times out.                     |
| ~plan-polsl-usos-base-url~        | ~"https://usosapi.polsl.pl/"~                 | USOS API installation.                                       |

** Interactive Commands

| Command                           | Description                                                             |
|-----------------------------------+-------------------------------------------------------------------------|
| ~M-x plan-polsl~                    | Open timetable buffer for your default schedule (USOS when logged in).  |
| ~C-u M-x plan-polsl~                | Open the plan.polsl.pl timetable of ~plan-polsl-id~, even when logged in. |
| ~M-x plan-polsl-search~             | Search for any teacher, group, or room timetable.                       |
| ~M-x plan-polsl-refresh-teachers~   | Force update the local cache of academic teachers from plan.polsl.pl.   |
| ~M-x plan-polsl-sync~               | Download and update your schedule in the Org-mode file for Org-Agenda.  |
| ~M-x plan-polsl-open-plan~          | Open the generated ~plan-polsl.org~ file.                                 |
| ~M-x plan-polsl-set-semester-start~ | Save the semester start date announced by the dean (once per semester). |
| ~M-x plan-polsl-note~               | Create or open a note for the class at point (~n~ in the timetable).      |
| ~M-x plan-polsl-event-create~       | Create an event on the day at point (~c~ in the timetable).               |
| ~M-x plan-polsl-event-edit~         | Edit the event at point (~e~ in the timetable).                           |
| ~M-x plan-polsl-event-delete~       | Delete the event at point (~D~ in the timetable).                         |
| ~M-x plan-polsl-usos-setup~         | Enter and privately store your USOS API Consumer Key and Secret.        |
| ~M-x plan-polsl-usos-login~         | Log in to USOS (opens the browser, asks for the PIN).                   |
| ~M-x plan-polsl-usos-logout~        | Revoke and delete the stored USOS token (~C-u~: also forget the key).     |
| ~M-x plan-polsl-usos~               | Open the personal USOS timetable regardless of ~plan-polsl-usos-default~. |
| ~M-x plan-polsl-usos-sync~          | Export the USOS timetable to Org regardless of ~plan-polsl-usos-default~. |

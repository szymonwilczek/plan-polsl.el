*plan-polsl.el* to pakiet dla GNU Emacsa integrujący system planów zajęć *Politechniki Śląskiej* ([[https://plan.polsl.pl/][plan.polsl.pl]]) z *Org-mode* oraz *Org-Agenda*.

Pobiera plan bezpośrednio z serwerów uczelni, parsuje współrzędne siatki godzinowej i sal, opcjonalnie filtruje zajęcia pod sekcję laboratoryjną oraz generuje czysty kalendarz w Org-mode.

* Możliwości

- *Integracja z plan.polsl.pl*
- *Filtrowanie sekcji laboratoryjnych*
- *Znaczniki powtarzalności*
- *Rejestracja w Org-Agenda*

* Konfiguracja (use-package)

Wszystkie parametry konfiguruje się bezpośrednio w definicji pakietu w Emacsie:

#+begin_src elisp
  (use-package plan-polsl
    :load-path "~/Dokumenty/GitHub/plan-polsl.el"
    :custom
    (plan-polsl-group-id "343266256")                              ;; ID grupy z plan.polsl.pl
    (plan-polsl-section nil)                                       ;; nil = pełny plan, lub np. "10"
    (plan-polsl-target-file "~/Dokumenty/writings/plan-polsl.org") ;; Ścieżka docelowa pliku Org
    (plan-polsl-auto-add-to-agenda t))                             ;; Dodaj do Org-Agenda
#+end_src
